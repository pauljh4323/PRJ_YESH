Privacy Policy — Oracle Machine

Last updated: September 8, 2026

Oracle Machine is a simple, offline random-character "slot" game. You tap a button, five slots fill with randomly generated characters, and that's it — there is no gameplay history, no accounts, and nothing saved between sessions.

What data this app collects

None. Oracle Machine does not collect, store, transmit, or share any personal data, gameplay data, or device information. There is no user account system, no analytics, no crash reporting, no advertising, and no third-party services of any kind built into the app. Everything the app does — generating and displaying random characters — happens entirely on your device, and nothing ever leaves it.

About the app's Android permissions

The Android build of this app requests the standard INTERNET permission. This permission is included by default by the underlying app framework (Capacitor) that packages the app for Android — it is not used by Oracle Machine to send or receive any data. The app's code contains no network requests of any kind. We're noting this permission explicitly, rather than omitting it, so this policy stays accurate to what's actually in the app package.

Third-party services

None. Oracle Machine does not integrate any third-party analytics, advertising, or tracking SDKs.

Children's privacy

Since the app collects no data from anyone, it does not knowingly collect any information from children or any other users.

Changes to this policy

If Oracle Machine's data practices ever change, this page will be updated and the "last updated" date above will reflect the change.
